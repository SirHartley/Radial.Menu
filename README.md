# Campaign Radial Menu

A customizable radial menu for campaign abilities.

- **Use:** Hold **B**, **left Ctrl**, or **right Ctrl**, move onto an ability, then release to activate.
- **Cancel:** Release in the center or press **Escape**.
- **Customize:** Hold **left-click** on a slot for half a second to assign an ability, clear it, or create a submenu. Hover over a submenu and move outward to select its abilities.
- **Settings:** Change hotkeys, slot counts, labels, tile tint, selection by direction, and animations in **LunaLib’s mod settings**.

Your layout is shared across campaigns. Opening the wheel **does not pause the game**.

**Install:** Extract the [download](https://github.com/SirHartley/Radial.Menu/releases) into Starsector’s `mods` folder and enable **Campaign Radial Menu**. Requires **LunaLib** and **LazyLib**.
